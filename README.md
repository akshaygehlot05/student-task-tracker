# Student Task Tracker

A full-stack MERN Task Tracker application built using React, Node.js, Express.js, MongoDB Atlas, Axios, and Tailwind CSS.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Responsive modern UI
- MongoDB cloud database integration
- REST API backend

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- Vite

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose
